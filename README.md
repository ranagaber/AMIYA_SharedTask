 # MBZUAI at AMIYA 2026
 
Repository for the paper: "_MBZUAI at AMIYA Shared Task 2026: Adapting Open-Source LLMs for Dialectal Arabic_"

This repository contains the code developed for our submission to the AMIYA 2026 Shared Task on Arabic Dialect Adaptation. It includes data preprocessing pipelines, model training scripts, and experiment configurations used in our system.


 All evaluations were done on **Al-Qasida** benchmark
